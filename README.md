## 🇧🇷 Sobre o Projeto

O **Auto Mecânica Vadão** é um sistema web moderno e responsivo desenvolvido para o gerenciamento ágil de Ordens de Serviço (OS) de oficinas mecânicas. O projeto foi estruturado para aliar um layout clássico de papel timbrado corporativo (ideal para impressão e geração de PDF em página única A4) com uma arquitetura moderna de persistência de dados em nuvem.

### 🚀 Funcionalidades
- **Autenticação Segura:** Tela de login restrita para operadores.
- **Gerenciamento de Ordens de Serviço:** Cadastro completo de dados do cliente, veículo (placa, marca, ano, cor, km) e datas de entrada/entrega.
- **Tabela Dinâmica de Itens:** Adição e remoção dinâmica de peças e serviços com cálculo automático em tempo real de materiais, mão de obra e valor total.
- **Central de Consulta:** Filtro rápido para buscar ordens de serviço anteriores por nome, número da OS, telefone, placa ou data.
- **Impressão / Exportação PDF Otimizada:** Layout desenhado especificamente para caber perfeitamente em 1 página A4 ao gerar PDF ou imprimir pelo navegador/celular.
- **Banco de Dados em Nuvem (Firebase Firestore):** Dados salvos de forma segura e acessíveis de qualquer lugar (pronto para deploy na Vercel).

### 🛠️ Tecnologias Utilizadas
- **HTML5 & CSS3** (Estilização profissional e regras de mídia `@print`)
- **Bootstrap 5 & Font Awesome** (Componentes responsivos e ícones)
- **JavaScript (ES6+)** (Manipulação de DOM e lógica de cálculo)
- **Firebase Firestore** (Banco de dados NoSQL em nuvem)

## 🇺🇸 About the Project

**Auto Mecânica Vadão** is a modern and responsive web application designed for fast management of Service Orders (OS) for automotive repair shops. The project combines a classic corporate letterhead layout (optimized for single-page A4 printing and PDF export) with a modern cloud-based data architecture.

### 🚀 Features
- **Secure Authentication:** Restricted login screen for authorized operators.
- **Service Order Management:** Complete record of customer details, vehicle info (license plate, brand, year, color, mileage), and entry/delivery dates.
- **Dynamic Items Table:** Add or remove parts and labor dynamically with real-time automatic calculation of materials, labor costs, and grand totals.
- **Search Center:** Quick filtering to search past service orders by client name, OS number, phone, license plate, or date.
- **Optimized Print / PDF Export:** Layout meticulously structured to fit strictly on a single A4 page when printing or exporting via browser/mobile.
- **Cloud Database (Firebase Firestore):** Secure data persistence accessible anywhere (ready for Vercel deployment).

### 🛠️ Tech Stack
- **HTML5 & CSS3** (Professional styling and `@print` media queries)
- **Bootstrap 5 & Font Awesome** (Responsive UI components and icons)
- **JavaScript (ES6+)** (DOM manipulation and calculation logic)
- **Firebase Firestore** (Cloud NoSQL database)
